## 🚀 Rodando Localmente

```bash
# Clone o repositório
git clone https://github.com/igor-silva-santos/orbe.git

# Instale as dependências
cd orbe
npm install

# Rode em desenvolvimento
npm run dev
```

Acesse `http://localhost:3000`
