## 🚀 Funcionalidades Implementadas

### ✅ Frontend
- **Interface Completa**: Header fixo, sistema de temas (dark/light) e navegação responsiva.
- **Pesquisa Global**: Barra lateral com filtros rápidos e resultados em tempo real.
- **Super Modal**: Detalhes profundos de cada mídia ao clicar no MidiaCard.
- **Carrosséis**: Navegação temporal dinâmica para diferentes categorias.

### ✅ Backend
- **Sincronização Real**: Dados vindos diretamente das APIs TMDB, Anilist e IGDB.
- **Endpoints REST**: Listagem, busca, tendências e autenticação.
- **Segurança**: Fluxo completo de login, cadastro e proteção de rotas com JWT.

## 🛠️ Como Executar

### 1. Backend (Flask)
```bash
cd backend
python -m venv venv
source venv/bin/activate # Windows: .\venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

### 2. Frontend (Next.js)
```bash
cd frontend
npm install
npm run dev
```
